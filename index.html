Help & Documentation

Getting Started

Welcome to CITIBIM Professional Gantt Dashboard! This tool helps you manage and visualize project timelines.

  • Dashboard: View your Gantt chart timeline
  • Summary: Overview of project KPIs and charts
  • Projects: Manage data sources and sheets
  • Team: View team workload and assignments
  • Settings: Configure Google Sheets integration

Importing Data

You can import project data from CSV files or Google Sheets:

  1. Click the "Import" button in the top bar
  2. Upload a CSV file or enter a Google Sheets URL
  3. Map columns to task fields (name, start date, end date, etc.)
  4. Import the data to create tasks

Google Sheets Integration

To enable live sync with Google Sheets:

  1. Publish your Google Sheet as CSV
  2. Copy the published CSV URL
  3. Paste it in Settings and click "Sync Now"
  4. Data will auto-sync every 5 minutes

Keyboard Shortcuts

  • Ctrl+S - Save tasks
  • Ctrl+E - Export data
  • Ctrl+I - Open import wizard

Troubleshooting

  • Import fails: Check CSV format and column mapping
  • Map not loading: Ensure Leaflet.js is loaded
  • Data not saving: Check browser localStorage
  • Google Sheets sync: Verify the URL is published correctly
